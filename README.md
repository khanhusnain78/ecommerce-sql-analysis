# E-Commerce SQL Data Analysis Project

## Project Overview

This project analyzes an E-commerce dataset using PostgreSQL to uncover business insights related to customer behavior, sales trends, product performance, and delivery efficiency.

The analysis includes **33 SQL queries** organized into multiple sections such as exploratory analysis, revenue insights, customer behavior, product performance, seller analysis, and order delivery performance.

---

## Business Problem

E-commerce platforms generate large volumes of transactional data including orders, customers, payments, products, and sellers. Without proper analysis, businesses cannot extract meaningful insights from this data.

This project aims to answer key business questions such as:

* Which products generate the most revenue?
* Which customers drive the most sales?
* Which sellers perform best on the platform?
* How do orders trend over time?
* How efficient is the delivery system?

---

## Dataset Information

The dataset represents a Brazilian E-commerce marketplace containing data about:

* Customers
* Orders
* Order Items
* Payments
* Products
* Sellers
* Reviews

The dataset was analyzed using **PostgreSQL**.

---

## Key Analysis Performed

### 1. Exploratory Data Analysis

Understanding dataset structure, number of records, and basic distribution.

### 2. Revenue Analysis

Identifying high revenue products, top categories, and total sales patterns.

### 3. Customer Analysis

Understanding repeat customers and identifying top spending customers.

### 4. Product Performance

Analyzing product categories contributing the most to sales.

### 5. Seller Performance

Evaluating seller revenue and performance across the marketplace.

### 6. Orders and Delivery Analysis

Studying order trends, delivery time, and percentage of late deliveries.

---

## Key Insights

* A small number of product categories generate a large share of total revenue.
* Certain cities contribute significantly higher repeat customers.
* A small group of customers accounts for a large portion of total spending.
* Seller performance varies significantly across the platform.
* Approximately **8% of orders are delivered late**, highlighting potential logistics improvements.
